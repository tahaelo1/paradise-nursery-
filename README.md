# Paradise Nursery 🌿

**Paradise Nursery** is a dynamic e-commerce shopping cart application for an online plant shop. Built with React and Redux Toolkit, it allows users to browse beautiful houseplants, add them to a cart, and manage their selections with ease.

## Project Name

**Paradise Nursery Shopping Application**

## Features

- 🌱 Browse 18+ unique houseplants across 3 categories
- 🛒 Add plants to cart with one click
- 🔢 Dynamic cart quantity counter in the navbar
- ➕➖ Increase/decrease item quantities in the cart
- 🗑️ Remove individual items from the cart
- 💰 Live total cost calculation
- 📱 Responsive, mobile-friendly design

## Tech Stack

- React 18
- Redux Toolkit
- React Redux
- Vite

## Getting Started

```bash
npm install
npm run dev
```
